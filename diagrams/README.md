# Diagrams

These `.mmd` files are [Mermaid](https://mermaid.js.org/) diagrams. GitHub renders Mermaid code blocks natively in Markdown, and most Mermaid files render automatically in the GitHub file preview.

Files:
- `network-architecture.mmd` — lab network + monitoring/alerting flow
- `attack-detect-respond-harden.mmd` — the security lifecycle used for every threat scenario
- `production-architecture.mmd` — production-equivalent architecture (not deployed, for comparison)

To export as PNG/SVG for the `screenshots/` folder or a slide deck, use the [Mermaid Live Editor](https://mermaid.live) or the `mmdc` CLI (`@mermaid-js/mermaid-cli`).
